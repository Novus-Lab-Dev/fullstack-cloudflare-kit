# Common Unique UI Blocks
### 1. Core Primitives & Basic Elements

* **Button:** Primary, secondary, icon buttons, and button groups.
* **Inputs & Controls:** Text/password inputs, textareas, select/dropdowns, checkboxes, radios, and switch (toggles).
* **Card / Panel:** Container blocks and stat/KPI cards.
* **Badge / Tag / Status Pill:** Status indicators and role badges.

### 2. Navigation & Layout

* **Sidebar / Topbar / Header:** Core app structure and navigation bars.
* **Tabs & Breadcrumbs:** Page navigation and section switching.
* **Page Shell / Content Container:** Main page content wrappers.

### 3. Data Display & Tables

* **Table / Data Grid / List View:** Server-paginated data lists and table shells.
* **Stat / KPI Cards / Metric Panel:** Dashboard metrics or summary cards.
* **Filter Bar & Search Box:** Data filtering and search controls.
* **Pagination:** Pagination controls for lists and tables.

### 4. Forms & Validation

* **Form Wrappers & Sections:** Form shells and field shells.
* **Advanced Inputs:** File uploads, searchable comboboxes, and date pickers.
* **Validation & Errors:** Inline validation messages and server error displays.

### 5. Overlays & Modals

* **Modal / Dialog:** Confirmation and detail dialogs.
* **Drawer / Sheet / Side Panel:** Side panels and create/edit sheets.
* **Dropdown Menu / Popover / Tooltip:** Interactive overlays and menus.

### 6. Feedback & States

* **Toast / Notifications:** Success and action feedback (e.g., Sonner integration).
* **Empty State:** UI displayed when no data is available.
* **Loading State:** Skeleton loading states and spinners.

### 7. Dashboard & Special Blocks

* **Charts & Graphs:** Revenue trends, donut charts, or bar charts.
* **Rich Text Editor:** WYSIWYG editor blocks.
* **Widgets & Calendar:** Recent activity feeds, upcoming tasks, or calendar blocks.
